# Next-Videos Chrome Extension

Official Chrome Browser Extension for **Next-Videos** video & audio downloader.

---

## ✨ Features
1. **One-Click Video Detection**: Automatically detects YouTube, TikTok, Instagram, Facebook, X (Twitter), Vimeo, and 1000+ other video URLs from your active browser tab.
2. **Right-Click Context Menu**: Right-click on any video, link, or page and choose **"Download Video with Next-Videos"**.
3. **Format & Quality Picker**: Choose 1080p, 4K, 720p, or MP3 Audio directly inside the popup.
4. **Real-time Download Progress**: Visual progress bar linked to Next-Videos backend server.
5. **Configurable Server**: Set local development server (`http://localhost:3000`) or your deployed production URL in Settings.

---

## 🚀 How to Install in Google Chrome (Step-by-Step)

### Step 1: Open Chrome Extensions
1. Open Google Chrome.
2. Address bar mein likhein: `chrome://extensions` aur **Enter** press karein.
   *(Ya top-right mein 3 dots menu -> **Extensions** -> **Manage Extensions** par click karein).*

### Step 2: Enable Developer Mode
- Top-right corner mein **Developer mode** ka toggle switch hoga, usay **ON** kar dein.

### Step 3: Load the Extension
1. Top-left par **Load unpacked** button par click karein.
2. Is folder ko select karein:
   ```text
   C:\Users\IAHQ-agaria\Desktop\Next-Videos-main\Next-Videos-main\extension
   ```
3. **Select Folder** par click karein.

### Step 4: Pin & Use
1. Chrome toolbar mein Puzzle icon (Extensions) par click karein.
2. **Next-Videos Downloader** ke samne **Pin** icon par click karein.
3. Ab kisi bhi YouTube ya video page par ja kar extension icon par click karein aur direct download karein!

## ⚙️ Backend Connection
Extension ko chalane ke liye Next-Videos backend server running hona chahiye:
- Default Port: `http://localhost:3005`
- Agar aapka server kisi aur port ya domain par hai, toh extension ke top-right gear (⚙️) icon par click karke Server URL update kar sakte hain.
